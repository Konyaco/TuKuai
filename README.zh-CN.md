## 为什么来土块棋牌室

- **牌真的摆在桌上。** 手牌立起来朝着自己，出过的牌落在桌子中间，路过的人都能围观。打开沉浸视角，直接点桌上的牌出牌。
- **永远不缺人。** 空位随时加电脑，分简单、普通、困难三档；有人离开或掉线，电脑接着替他打。大家都走开了，牌局就停下来等人回来。
- **一坐一晚上。** 一场比赛连打好几局、累计比分，每局都存了回放，能换任意座位的视角重看，牌桌还记着每个人的战绩。
- **把屋子布置成你的样子。** 牌桌和凳子有各种木头，桌布和坐垫随便染色，牌背、牌面有好几套。大方桌能坐 8 个人。

## 开始游玩

### 下载

从 [Releases](https://github.com/Konyaco/TuKuai/releases/latest) 下载对应 Minecraft 版本和加载器的 jar，例如 `tukuai-fabric-1.21.1-<版本>.jar`。服务器和每位玩家都要安装。支持 Minecraft 26.3、26.2、26.1.2 和 1.21.1，还需要：

| 加载器 | 前置模组 |
| --- | --- |
| NeoForge 26.1.2, 26.2, 26.3 | [Kotlin for Forge](https://modrinth.com/mod/kotlin-for-forge) 6.4.0 或更新 |
| NeoForge 1.21.1 | [Kotlin for Forge](https://modrinth.com/mod/kotlin-for-forge) 5.12.0 或更新 |
| Fabric | [Fabric API](https://modrinth.com/mod/fabric-api)、[Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) 1.13.13 或更新 |

苍白橡木的牌桌和凳子需要 26.1.2 或更新版本，1.21.1 还没有苍白橡木。

### 上手

1. **放下牌桌**。牌桌占 3×3 格，会从点击的方块向前展开，前方和左右需留出空地。
2. **右键打开牌桌**，点「坐这里」入座，空位可点「加电脑」补上。
3. **选择游戏和规则**，点「开始」。

凳子放在牌桌有座位一侧的外边正中，右键凳子即可坐到对应座位。大方桌占 5×5 格，每边两个座位，最多坐 8 人。

界面支持简体中文、繁体中文、英文、日文和韩文，随游戏语言切换。

<details>
<summary><b>服务器设置</b></summary>

首次开服（或进入单人存档）后会生成 `config/tukuai-server.properties`，修改后执行 `/reload` 或重启生效。

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `allowBots` | `true` | 是否允许电脑入座 |
| `botDelaySeconds` | `1.1` | 电脑出牌前的平均等待秒数 |
| `saveReplays` | `true` | 是否保存回放 |
| `maxReplays` | `500` | 回放保留上限，超出时删除最旧的；`0` 表示不限 |
| `keepStats` | `true` | 是否记录战绩 |

</details>

<details>
<summary><b>开发</b></summary>

需要 JDK 25；Minecraft 1.21.1 要用的 JDK 21 由 Gradle 自动下载。

```sh
./gradlew build                        # 编译、测试，并打出每个加载器、每个 Minecraft 版本的 jar
./gradlew :mc26:fabric-26.3:runClient  # 用 Fabric 启动 Minecraft 26.3
./gradlew :neoforge-1.21.1:runClient   # 用 NeoForge 启动 Minecraft 1.21.1
```

| 目录 | 内容 |
| --- | --- |
| `engine` | 规则、电脑和回放，纯 Kotlin，不依赖 Minecraft |
| `common` | 所有加载器和 Minecraft 版本共用的 Minecraft 代码和资源，按最新版 Minecraft 写 |
| `mc26` | Minecraft 26.1.2、26.2、26.3 合成的一个 [Stonecutter](https://stonecutter.kikugie.dev/) 项目：`src` 里是 `compat` 包、渲染器、各加载器的入口、物品模型和配方，版本之间不同的地方用 `//?` 注释标出；`versions/<加载器>-<minecraft>/gradle.properties` 是各自的版本号 |
| `versions/1.21.1` | Minecraft 1.21.1：`gradle.properties` 里的各项版本，让它用上最新版 Minecraft 名字的 `compat` 包，渲染器、物品模型和配方 |
| `versions/1.21.1/fabric`、`versions/1.21.1/neoforge` | 1.21.1 下各加载器的入口和注册 |

加入新游戏：

1. 在 `engine` 中实现 `GameDefinition`，并在 `TuKuai.init()` 中注册到 `GameRegistry`。
2. 在 `common/.../client` 中实现 `GameUi`，并在 `TuKuaiClient.init()` 中注册到 `GameUis`。
3. 在每个语言文件中加入 `tukuai.game.<id>` 和各规则的名称。

测试：

```sh
./gradlew :engine:test                           # 规则与电脑的单元测试
./gradlew :mc26:fabric-26.1.2:runClientGameTest  # 启动游戏实际打几局并截图
./gradlew :mc26:fabric-26.1.2:runMultiplayerTest # 专用服务器加两个客户端的联机测试
./gradlew :fabric-1.21.1:runSmokeTest            # 在 Minecraft 1.21.1 上每种玩法各打一局并截图
./gradlew :mc26:neoforge-26.3:runSmokeTest       # 在任一 26.x 版本和加载器上做同样的测试
TUKUAI_SHOWCASE=en_us,zh_cn ./gradlew :mc26:fabric-26.1.2:runClientGameTest   # 拍摄本文的截图
```

提交信息格式为 `[type](scope) Title`。依赖版本见 `gradle.properties` 和 `versions/<minecraft>/gradle.properties`。

</details>
